# Changelog

## 0.1.0

The first release.

- Menu Core menus in INI, YAML and JSON: completion, checks as you type, hovers and go-to-definition for menus, items, conditions, actions and placeholders - including the names plugins register in code.
- Config Core configs: completion, checks and hovers for the files a plugin loads with `configs.load`, against the shape it declares - with or without an import line.
